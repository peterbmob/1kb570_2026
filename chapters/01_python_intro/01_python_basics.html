1.1 Variables and Data Types#

A variable is just a labelled box that holds a value so you can refer to it by name instead of retyping the value everywhere. Python figures out the type of box automatically from what you put in it — you never have to declare “this is a number” the way some other languages require. The four most common primitive types are:

Type

Example

Use

int

3

Integer counts, indices

float

3.14

Measured values

str

'ZnO'

Labels, file names

bool

True

Flags, conditions

Why bother distinguishing them at all? Because operations behave differently depending on type — 3 / 2 gives a fractional result (1.5), string concatenation ('Li' + 'FePO4') glues text together rather than adding numbers, and mixing an int count of atoms with a float measured mass is exactly the distinction you want to keep straight when writing formulas below.

# ── Material properties as Python variables ──────────────────────────────────
material_name   = 'LiFePO4'          # str
density         = 3.6                # g/cm³  (float)
num_formula_units = 4                # int
is_cathode      = True               # bool

print(type(material_name), material_name)
print(type(density),       density)
print(type(num_formula_units), num_formula_units)
print(type(is_cathode),    is_cathode)

1.2 Lists, Tuples, and Dictionaries#

Python gives you three everyday containers, and choosing the right one is mostly about answering “will this collection’s contents ever change, and do I need to look things up by name or by position?”

  • list — ordered, mutable collection. Use it for a growing series of measurements (you can append a new reading as it comes in).

  • tuple — ordered, immutable collection (good for fixed data like lattice parameters — once a crystal’s unit cell is defined, you don’t want code elsewhere in the notebook to accidentally change one of its values).

  • dict — key-value store (good for labelled material properties, where you want to retrieve a value by its name, e.g. cathode['capacity_mAh_g'], rather than by remembering “it’s the 3rd item in the list”).

# ── List: measured capacities from repeat experiments ────────────────────────
capacities_mAh_g = [152.3, 155.1, 149.8, 153.7, 151.2]  # mAh/g

print('All measurements:', capacities_mAh_g)
print('First value:     ', capacities_mAh_g[0])   # indexing from 0
print('Last value:      ', capacities_mAh_g[-1])  # negative index
print('Slice [1:3]:     ', capacities_mAh_g[1:3]) # half-open interval

# Appending and removing
capacities_mAh_g.append(154.0)
print('After append:    ', capacities_mAh_g)

1.3 Control Flow#

Control flow is how a program decides what to do next: if picks between alternatives based on a condition, for repeats an action once per item in a collection (e.g. once per sample), and while repeats an action until a condition becomes false (useful when you don’t know in advance how many repetitions you’ll need — like simulating a titration until the endpoint is reached). Almost every data-processing script you write in this course is built from these three tools, combined with functions (Section 1.4).

# ── if / elif / else ─────────────────────────────────────────────────────────
def classify_capacity(cap_mAh_g):
    """Return a quality label based on specific capacity."""
    if cap_mAh_g >= 200:
        return 'Excellent'
    elif cap_mAh_g >= 150:
        return 'Good'
    elif cap_mAh_g >= 100:
        return 'Acceptable'
    else:
        return 'Poor'

for cap in [230, 165, 120, 85]:
    print(f'{cap:>5} mAh/g  →  {classify_capacity(cap)}')

1.4 Functions#

A function packages up a calculation you’ll want to repeat — write the recipe once, then reuse it by name instead of copy-pasting the same lines (and risking a typo in one of the copies). Functions make code reusable and readable.

Use default arguments for common values and keyword arguments when calling.

def specific_capacity(charge_mAh, mass_g, efficiency=1.0):
    """
    Calculate specific capacity.

    Parameters
    ----------
    charge_mAh : float   Total charge in mAh
    mass_g     : float   Active material mass in grams
    efficiency : float   Coulombic efficiency (0–1), default 1.0

    Returns
    -------
    float : specific capacity in mAh/g
    """
    return (charge_mAh * efficiency) / mass_g


# Using default efficiency
cap = specific_capacity(charge_mAh=85.6, mass_g=0.5)
print(f'Specific capacity: {cap:.1f} mAh/g')

# Including efficiency
cap_eff = specific_capacity(85.6, 0.5, efficiency=0.97)
print(f'With 97% efficiency: {cap_eff:.1f} mAh/g')

Specific capacity: 171.2 mAh/g
With 97% efficiency: 166.1 mAh/g

# ── Functions returning multiple values ───────────────────────────────────────
import math

def interplanar_spacing_cubic(h, k, l, a):
    """
    d-spacing for cubic crystal: d = a / sqrt(h²+k²+l²)
    Returns d in same units as a, and 2theta in degrees for Cu Kα (λ=1.5406 Å).
    """
    d = a / math.sqrt(h**2 + k**2 + l**2)
    lambda_CuKa = 1.5406  # Å
    sin_theta = lambda_CuKa / (2 * d)
    if abs(sin_theta) <= 1:
        two_theta = math.degrees(2 * math.asin(sin_theta))
    else:
        two_theta = float('nan')
    return d, two_theta

# XRD peaks for gold (FCC, a = 4.078 Å)
a_Au = 4.078
planes = [(1,1,1), (2,0,0), (2,2,0), (3,1,1)]

print(f'{"hkl":<10} {"d (Å)":<12} {"2θ (°)"}')
print('-' * 32)
for hkl in planes:
    d, tt = interplanar_spacing_cubic(*hkl, a=a_Au)
    print(f'{str(hkl):<10} {d:<12.4f} {tt:.3f}')

1.5 List Comprehensions#

List comprehensions are a concise, Pythonic way to build lists from sequences. [expression for item in sequence if condition] reads almost like English: “for each item in the sequence, if the condition holds, compute the expression and collect the results into a new list.” It replaces a multi-line for loop with .append() calls with a single readable line — useful, but only reach for it when the expression stays simple; a plain loop is often clearer for anything more complex.

# Temperatures in Celsius → Kelvin
T_C = [25, 100, 200, 400, 600, 800]
T_K = [t + 273.15 for t in T_C]
print('T_K:', T_K)

# Filter: keep only samples with capacity > 160 mAh/g
all_capacities = [148, 161, 169, 172, 145, 158, 163, 141]
good = [c for c in all_capacities if c > 160]
print('Good capacities:', good)

# Combined transformation + filter
# Convert conductance (S) to resistivity (Ω·cm) only for valid (positive) values
conductances_S = [0.12, -0.01, 0.34, 0.0, 0.22, 0.09]  # -0.01 is erroneous
thickness_cm = 0.05
area_cm2 = 1.0
resistivities = [thickness_cm / (g * area_cm2) for g in conductances_S if g > 0]
print('Resistivities (Ω·cm):', [f'{r:.3f}' for r in resistivities])

1.6 String Formatting (f-strings)#

f-strings (Python 3.6+) are the modern standard for formatting output.

sample_id = 'NMC_T800_t12'
capacity  = 198.4267
retention = 0.9341

# Basic f-string
print(f'Sample: {sample_id}')

# Number formatting
print(f'Capacity: {capacity:.2f} mAh/g')     # 2 decimal places
print(f'Capacity: {capacity:8.2f} mAh/g')    # width 8, right-aligned
print(f'Retention: {retention:.1%}')          # percentage
print(f'Retention: {retention:.4e}')          # scientific notation

# Building a report line
def report_line(sid, cap, ret):
    flag = '✓' if ret > 0.9 else '✗'
    return f'{flag} {sid:<20} {cap:>8.2f} mAh/g   {ret:.1%} retention'

print()
print(report_line('NMC_T800_t12', 198.4, 0.934))
print(report_line('NMC_T700_t06', 155.1, 0.871))
